Release notes for v1.1

Bento Project Studio v1.1 is a feature and maintenance update focused on audio editing, drag-and-drop workflows, new track types, effects, scenes, and overall usability.

New features
  • Added per-zone Audio Editor support for multisample zones, with undo/redo, so individual samples can be trimmed, processed and fine-tuned directly from the Zone Map.
  • Added Overdrive FX support, including editing and playback.
  • Added Scene support for capturing and recalling sequence states.
  • Added Shredder track support, including editing and playback.
Improvements
  • Improved reverb playback preview, designed to give a more realistic impression of how projects will sound on the Bento hardware, although it is not an exact one-to-one reproduction.
  • Improved sample workflow consistency between generated samples, browser samples and external files.
  • Improved velocity-to-gain behavior.
Bug fixes
  • Fixed drag-and-drop of samples generated by the Sound Generator.
  • Fixed drag-and-drop support from the system file browser.

Release notes for v1.8
New features
  • Sequencer
    • MIDI Out for sequences: sequences can now send MIDI output.
    • Note labels: notes can now display labels in the sequencer.
    • Note probability
  • New sound generators
    • Glitch
    • Noise Texture
    • FX: Riser, Downlifter, Impact, Sweep, Blast
  • Audio Editor
    • New effect: Transient Shaper
    • Trim
    • Loop crossfade editing
    • Loop Finder: find smoother loop points.
  • Recorder: record from a hardware device or from an internal source (resampling).
  • Preview volume controls
  • Playback: bidirectional loops, reverse playback, loop crossfade.
Improvements
  • Improved time-stretching audio quality.
  • Real-time changes for level, pitch, filter, and send effects.
  • Improved sound generators with more control parameters: Wavetable, Drums, and FX.
  • Notes can now be colored based on velocity or probability.
  • Export
    • Use the pad number in track and file names.
    • DAWproject: patterns A/B/C/D are now clips in the same track.
Changes
  • Sound Generator
    • Pluck is now renamed Physical.
    • Fractal is replaced by Glitch.
Bug fixes
  • Fixed Save As behavior when a sample was edited but not already saved.
  • Fixed missing polyphony parameter in Clip Mode.
